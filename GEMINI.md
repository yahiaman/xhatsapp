# Workspace Instructions & Rules

## Browser Preference
- ALWAYS use **Google Chrome** (`C:\Program Files\Google\Chrome\Application\chrome.exe`) for all web tasks, URL launching, and browsing operations triggered by Antigravity.
- NEVER launch Microsoft Edge, and NEVER use generic `Start-Process <URL>` commands that delegate to the Windows default browser.
- The user keeps Microsoft Edge as their Windows system default browser, but Chrome is specifically designated for Antigravity.
